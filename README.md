# 🧮 C# Windows Forms Calculator

A desktop calculator application built from scratch using **C#** and **Windows Forms**, developed as part of my continuous learning in desktop application development.

---

### 🚀 What I Practiced & Implemented in This Project:
* **State Management:** Tracking inputs, operations, and execution flags (`bool flag`, state variables).
* **Separation of Concerns:** Structuring the code into modular functions (`readNumberToScreen`, `readOperation`, `calculate`).
* **Error Handling & Safety:** Implemented safe division logic (`safeDivision` and `isValidDenominator`) to prevent runtime application crashes (e.g., dividing by zero).
* **Enumerations (`enum`):** Managing mathematical operations cleanly and scalably.
